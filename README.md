# Anonychat
# Anonymous Telegram Chat Bot

This is a fully anonymous, gender-based Telegram chat bot. Features include:

- Gender selection: Male, Female, or Random
- Random anonymous pairing with avatars and nicknames
- Fake typing indicators and real-time feedback
- Command support: /start, /stop, /next, /status, /clearqueue, /online
- Admin broadcast and moderation tools
- MongoDB-based persistent session and feedback storage

## Setup

1. Copy `.env.example` to `.env` and fill your values.
2. Run with `python main.py` or deploy using Docker.
